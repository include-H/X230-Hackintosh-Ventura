# 安装指南:从 U 盘到装完验证

目标机器:ThinkPad X230(Ivy Bridge,i5-3230M,HD 4000)。
目标系统:**macOS 11 – 15**。同一份 `EFI/`,靠 `Min/MaxKernel` 自动切档。

> 接手的人在动手前必须先做一件事:**换三码**([../AGENTS.md](../AGENTS.md) 第 2.4 节)。
> 除此之外基本可以照抄。

---

## 0. 先决定装哪个版本

| 系统 | 难度 | 装完要做什么 |
|---|---|---|
| **Big Sur 11** | ★ | 什么都不用做。HD 4000 原生加速、无线 `AirportItlwm_BigSur` 免驱 |
| Monterey 12 | ★★ | 跑 OCLP;无线的 Monterey 版 `AirportItlwm` 要自己去下(见 README) |
| **Ventura 13** | ★★ | 跑 OCLP;无线 `AirportItlwm_Ventura` 免驱 |
| Sonoma 14 / **Sequoia 15** | ★★★ | 跑 OCLP + 下 Metallib;无线改成 `itlwm` + **HeliPort** |

**第一次装,建议直接从 13 起步**(见 README「装哪个版本」):它无线原生、OCLP 也最省事。
先确认 USB / 声卡 / 电源管理都正常,再去碰 14 / 15 那两个无线要外挂 App 的版本。

> 老账:这台机器只有 AVX1、没有 AVX2。新版 Chromium / Electron 类应用会直接拒绝启动,
> 得挑老版本。Homebrew 对 Intel 也已是 Tier 3(见 README「已知问题」)。

## 1. 动手前确认

### 1.1 固件设置

| 项目 | 值 | 说明 |
|---|---|---|
| Boot Mode | **UEFI Only** | 不能是 Legacy / Both |
| CSM | **No(关)** | 开着能引导、进度条走一半,但进不去安装器 |
| SATA | **AHCI** | 不能是 Compatibility |
| VT-d | On | 与 `DisableIoMapper` Quirk 配合,不用关 |
| Secure Boot | Off | |
| 独显 | 无 | X230 只有核显,不用做 dGPU 屏蔽 |
| DVMT Pre-Allocated | **128 MB** | 出厂 BIOS 里隐藏,需先解锁(见下) |
| DVMT Total Gfx Mem | **Max** | 同上 |
| Intel ME / AMT | **On(开)** | 12 及以后必需:HD 4000 的 PAVP 会话要经 MEI 走,关了加速起不来(显存 4 MB、Dock 不透明)。见[`踩坑记录.md`](踩坑记录.md) 第 16 条 |

本机 BIOS 为 `G2ETB7WW (2.77)`。更老的版本大概率也能用,但上面几项必须能设。

**BIOS 需要先解锁**:上面那两项 DVMT 藏在 `Advanced → System Agent (SA) Configuration →
Graphics Configuration` 里,出厂固件看不到。用
[n4ru/1vyrain](https://github.com/n4ru/1vyrain/) 刷一次即可(不用编程器),刷完
`Advanced` 菜单就全了。经典 X230 仓库
[banhbaoxamlan/X230-Hackintosh](https://github.com/banhbaoxamlan/X230-Hackintosh)
也是这么要求的(它的 `Other/README_HARDWARE.md` 里写的就是 `DVMT Pre-Allocated = 128MB`)。

> **DVMT 和 EFI 里的 `framebuffer-stolenmem` 是一对,必须对齐**:
> EFI 那边声明显卡能从预留区拿走多少,BIOS 这边决定到底预留了多少。
> 预留量没到,驱动就会去用一段 BIOS 根本没留出来的内存 —— 症状是显存数字乱跳,
> 或者**加速器起不来**。细节见 [`踩坑记录.md`](踩坑记录.md) 第 10 节。
>
> **别顺手关掉 Intel ME**:它看着像「用不上的带外管理」,但 macOS 12+ 的 HD 4000
> 加速要靠它那条 PAVP 链路。做过 `me_cleaner` / HAP 的机器(或 BIOS 里关了 ME 的),
> 症状是「kext 都在、显存 4 MB、Dock 不透明」——回到 BIOS 打开即可,不用改 EFI。

### 1.2 无线网卡

本仓库按 **Intel Dual Band Wireless-AC 7260** 配的驱动,按系统版本自动选:

| 系统 | 用哪个 |
|---|---|
| 11 | `AirportItlwm_BigSur.kext` —— 原生 Wi-Fi 菜单,不用装别的东西 |
| 13 | `AirportItlwm_Ventura.kext` —— 同上 |
| 14 / 15 | `itlwm.kext` —— **要额外装 [HeliPort](https://github.com/OpenIntelWireless/HeliPort/releases)** |

- 装之前最好先把网卡换好,省得装完再拆机。
- 如果是原装 Centrino N-2200 / 6205,macOS 下无解,建议换卡。
- 如果是博通卡(如 BCM94352HMB),要换成 `AirportBrcmFixup` + `BrcmPatchRAM3` 那一套,
  参见 [`参考/经典仓库笔记.md`](参考/经典仓库笔记.md)。

### 1.3 硬盘

SSD,≥ 64GB。安装器本身约 12–16GB,U 盘至少 16GB(建议 32GB)。

## 2. 做安装 U 盘

### 2.1 有 Mac

```bash
# 下载对应的 "Install macOS xxx.app" 并放进 /Applications
# 用磁盘工具把 U 盘抹成 "Mac OS 扩展(日志式)" + "GUID 分区图",然后:
sudo /Applications/Install\ macOS\ Sequoia.app/Contents/Resources/createinstallmedia \
     --volume /Volumes/MyVolume --nointeraction
```

### 2.2 没有 Mac

1. Windows / Linux 上跑 [gibMacOS](https://github.com/corpnewt/gibMacOS) 下载安装器。
2. 先在 X230 上装个 Linux,用 Linux 版 OpenCore + `macrecovery`(OpenCorePkg 自带)
   下载恢复镜像,做成恢复 U 盘。

### 2.3 把 EFI 放进 U 盘

安装 U 盘直接用本仓库的 [`../EFI/`](../EFI),但**要把 config 换成装系统那份** ——
仓库里的 `config.plist` 是日常版(蓝牙开着),拿它装系统会 panic:

```bash
diskutil list                  # 找到 U 盘的 EFI 分区,一般叫 disk4s1
sudo diskutil mount disk4s1    # 挂到 /Volumes/EFI
cp -R /path/to/this/repo/EFI /Volumes/EFI/
cp /Volumes/EFI/EFI/OC/config-install.plist /Volumes/EFI/EFI/OC/config.plist  # 换成装系统版
ls /Volumes/EFI/EFI/OC/config.plist   # 确认拷进去了
```

> 两份 config 差什么、装系统为什么要关蓝牙,见 README「两份 config」一节。
> `tools/efi-sync.sh push` 是往**机器上的 ESP** 拷的(它会先备份 ESP 上的关键文件、
> 打印 `rsync --dry-run` 预览、覆盖、再回读 sha256 校验)。U 盘直接用 `cp -R`。

## 3. 第一次启动

1. 插 U 盘,开机按 **F12** 进 Boot Menu。
2. 选 **UEFI** 那一项里的 U 盘(名字带 `UEFI:` 前缀的那个)。
3. 看到 OpenCore 图形菜单(OpenCanopy)。
4. 选 **Install macOS ...**。

boot-args 里带着 `-v`,卡住时屏幕上会停在**最后一行字**上。把最后几行拍下来,
对照 [`踩坑记录.md`](踩坑记录.md) 找:

- 停在 `AppleUSBHostController` / `EHCI` 一带 → USB 相关
- 一直滚到 `Still waiting for root device`、最后是禁止符 → **根卷找不到**,
  常见于系统盘挂在 USB 桥后面(踩坑记录第 14 条)
- `ACPI Error ... AE_NOT_FOUND` → 见踩坑记录第 2 条(`_LID` 重命名)
- 卡一半进度条 → 回去把 CSM 关掉(踩坑记录第 1 条)
- `OC: Grabbed zero system-id for SB` → `SecureBootModel`(踩坑记录第 13 条)

**12 及以后的第一次开机可能自己崩一次,重启就好**——这不是故障,
是根卷补丁还没打,系统在用没有加速的兜底路径。

---

## 4. 安装

1. 进安装器后先开 **磁盘工具**:选目标 SSD → 抹掉 → 格式 `APFS` → 方案 `GUID 分区图`。
2. 退出磁盘工具,选 **安装 macOS**。
3. 中途会自动重启几次,每次都要从 OpenCore 菜单选对启动项:
   - 第一次重启后选 **macOS Installer**(安装阶段)
   - 再重启后选 **macOS**(刚装好的系统盘)
4. 进到「设置助理」就算装完了。

---

## 5. 装完之后

### 5.1 系统盘 ESP 换成日常版 config

U 盘里那份是装系统版(蓝牙关、带 `-v`)。装完之后,系统盘的 ESP 上要换成仓库里的
**日常版 `config.plist`**(蓝牙四件套开着、不带 `-v`),否则蓝牙永远起不来:

```bash
sudo diskutil mount disk0s1        # 系统盘的 EFI,分区号用 diskutil list 确认
cp -R /path/to/this/repo/EFI /Volumes/EFI/     # 整份覆盖,config.plist 就是日常版
ls /Volumes/EFI/EFI/OC/config.plist
```

> 只想换 config 也行:`cp EFI/OC/config.plist /Volumes/EFI/EFI/OC/config.plist`。

重启。此时蓝牙四件套开始加载(要不要冷启动见 5.4)。

### 5.2 联网

插网线最稳(Intel 82579LM 走 `IntelMausi`,免驱)。无线按 1.2 的表:
11 / 13 直接进 Wi-Fi 菜单,14 / 15 先装 HeliPort 再连。

### 5.3 显卡

```bash
system_profiler SPDisplaysDataType | grep -iE "Chipset|VRAM|Metal"
```

**Big Sur 11** 期望直接就是:

```
Chipset Model: Intel HD Graphics 4000
VRAM (Total): 1536 MB
Metal: Supported
```

**12 及以后**这一步必然是没加速的(显存 4 MB 或 1536 MB 但 `Metal` 不支持),
**去跑 OCLP 的 `Post-Install Root Patch`**,完整流程、前置检查、验证方法都在
[`OCLP.md`](OCLP.md)。跑完重启再来验一次。

> OCLP 跑了、补丁清单里也有 `Intel Ivy Bridge`,但 `kextstat | grep -i HD4000`
> 里**只有 `AppleIntelFramebufferCapri`**、`ioreg -lw0 -r -c IOAccelerator` 还是空的?
> 那是 AuxKC 只加载了一半。先按 [`OCLP.md`](OCLP.md) 第 6 节逐条排查 ——
> **别去动 `/Library/Extensions` 里 OCLP 放的那两份**,真正在跑的就是它们
> (EFI 那两条预链接注入会被 OpenCore 拒掉,见 [`OCLP.md`](OCLP.md) 第 8 节)。

> 「Dock 透明、窗口拖动不掉帧」才算真的好了。只看显存数字会被骗:
> 补丁打了一半的时候显存也可能显示 1536 MB。

### 5.4 声音 / 蓝牙 / 电源管理

```bash
# 电源管理:Ivy Bridge 走 AICPUPM,这里应为 0
sysctl machdep.xcpm.mode
kextstat | grep com.apple.driver.AppleIntelCPUPowerManagement

# 声音(ALC269,layout-id 18)
system_profiler SPAudioDataType | head -20

# 蓝牙
system_profiler SPBluetoothDataType | head -20
```

蓝牙要点:开关是灰的、点不开 → **彻底关机再开机**(不是「重新启动」),
`BCM20702` 的固件要冷启动才灌得进去。详见踩坑记录第 8 条。

### 5.5 三码 / 序列号

仓库里带的是**占位值**,系统能起来,但 iCloud / iMessage / FaceTime 用不了。
要正常用,得换成你自己生成的:

```bash
macserial -g MacBookPro9,2     # 取 SystemSerialNumber / MLB / SmUUID
```

把结果填进 `PlatformInfo/Generic`;`ROM` 用你自己有线网卡的 MAC 地址(6 字节)。
改完跑一遍 `ocvalidate` 再 `push` 到 ESP。

换完之后可以把 `SecureBootModel` 从 `Disabled` 改成 `Default` 开 Apple 安全启动。
**没换之前别动**(踩坑记录 13)。

> 别去抄别人的真码,也别在网上晒自己的。

## 6. 为什么安装和日常要分开

`BrcmPatchRAM3` 是蓝牙固件加载器。它在**安装器环境(BaseSystem)**下会去匹配 USB 蓝牙
并灌固件,而此时 USB 栈还没成型 → **kernel panic**
(实拍见 [`images/`](images/),完整栈在 [`踩坑记录.md`](踩坑记录.md) 第 3 条)。
所以蓝牙四件套在安装阶段必须缺席。

| kext | `config-install.plist`(装系统) | `config.plist`(日常) |
|---|---|---|
| `BrcmBluetoothInjector` | ❌ 关 | ✅ 开 |
| `BrcmFirmwareData` | ❌ 关 | ✅ 开 |
| `BrcmPatchRAM3` | ❌ 关 | ✅ 开 |
| `BlueToolFixup` | ❌ 关 | ✅ 开 |
| 其余 25 个 | 相同 | 相同 |

[`banhbaoxamlan/X230-Hackintosh`](https://github.com/banhbaoxamlan/X230-Hackintosh)
的思路也是「装系统阶段尽量少挂东西」——它的 Install USB 版连自定义 ACPI 都不加载。
本仓库保留了 ACPI(那份组合实测能进安装器),只是把蓝牙四件套关掉。

## 7. 故障速查

| 现象 | 大概率原因 | 处理 |
|---|---|---|
| 一开机就 `OC: Grabbed zero system-id for SB, ... halting` | `SecureBootModel` 开着,但 UUID 还是全零占位值 | 改 `Disabled`(踩坑记录 13) |
| 进度条卡一半 | CSM 开着 | BIOS 里关 CSM(踩坑记录 1) |
| 引导菜单都不出 | U 盘 EFI 分区没做好 / 选了 Legacy 项 | 重做 EFI,选带 `UEFI:` 的启动项 |
| `ACPI Error ... VID._INI AE_NOT_FOUND` | 加载了带 `_LID → XLID` 重命名的 config | 见踩坑记录 2 |
| 装系统时 kernel panic,栈里有 `BrcmFirmwareStore` | 蓝牙四件套开着 | U 盘 ESP 换成 `config-install.plist` 那份(踩坑记录 3) |
| 内置 USB 设备(摄像头/蓝牙/指纹)消失 | `EHC1→EH01` / `EHC2→EH02` 没生效,或端口地图没启用 | 见踩坑记录 4 与 [`USB定制.md`](USB定制.md) |
| 蓝牙图标有但开关是灰的 | 没冷启动 | 彻底关机再开(踩坑记录 8) |
| 12+ 显存只有 4 MB / Metal 不支持 | 还没跑 OCLP 的 root patch,或者只跑了一半 | 见 [`OCLP.md`](OCLP.md) 第 6 节 |
| OCLP 跑过了,但还是没加速,`ioreg -lw0 -r -c IOAccelerator` 是空的 | AuxKC 没把加速器带进来,或两个 kext 有两个来源在打架 | 先重启复查,再按 [`OCLP.md`](OCLP.md) 第 6 节查;来源冲突看第 8 节 |
| 触摸板 / 小红点失灵 | `SSDT-KBD` 没加载,或 VoodooPS2 被关 | 检查 `ACPI/Add` 与 `Kernel/Add` |
| 禁止符 / `Still waiting for root device` | 根卷找不到(常见于系统盘挂 USB 桥后面),**与显卡无关** | 见踩坑记录 14 |
| 14 / 15 的 Wi-Fi 菜单是空的 | `AirportItlwm` 没有 Sequoia 版,得用 `itlwm` + HeliPort | 见 1.2 |
