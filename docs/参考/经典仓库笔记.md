上游: <https://github.com/banhbaoxamlan/X230-Hackintosh>
OC 0.7.9 / Catalina + Big Sur + Monterey / SMBIOS 正式版 MacBookPro9,1

> 本目录还有另一份参考仓库 [`zyq8888/X230-MAC-OpenCore`](https://github.com/zyq8888/X230-MAC-OpenCore),
> **没有收录它的文件**,只在 `AGENTS.md` 3.4 记了它的坑。出处汇总见 [`README.md`](README.md)。

## 核心发现:它把 EFI 拆成两份

| | EFI-Install_USB(装系统用) | EFI(日常用) |
|---|---|---|
| **ACPI/Add** | **空** | 8 个 SSDT |
| **ACPI/Patch** | **空** | 9 条 |
| kext 数 | 8 个 | 19 个 |
| USB | USBInjectAll | USBPorts(地图) |
| SMBIOS | MacBookPro12,1 | MacBookPro9,1 |
| csr-active-config | 00000000 | 00000000 |
| boot-args | `-v -no_compat_check amfi_get_out_of_my_way=0x1 debug=0x100` | 同左 |

### 安装版的 8 个 kext
Lilu / VirtualSMC / WhateverGreen / AppleALC / IntelMausi / VoodooPS2(+4子) / USBInjectAll / EFICheckDisabler

### 安装版【没有】的
蓝牙(BlueTooth_BCM)、无线、SMCBatteryManager、SMCProcessor、ECEnabler、
BrightnessKeys、RestrictEvents、SidecarFixup、YogaSMC、USBPorts、VoodooSDHC、HibernationFixup

## 结论 / 启示
1. **装系统阶段不加载任何自定义 ACPI**,直接吃原厂 DSDT —— 把变数降到最低。
2. 蓝牙、电池、SMC 插件、无线这些**统统留到系统装好再加**。
3. 安装期用 USBInjectAll 保端口,日常期切 USBPorts 地图。
4. 装系统用的 SMBIOS 挑一个**系统原生支持**的机型(它用 12,1),日常再换回 9,x。

> 我们这次 panic 正是 BrcmPatchRAM3 在 BaseSystem 下崩的,与该仓库的做法完全吻合。

## 本仓库最后怎么用的

沿用它的思路,但落法更轻:

1. **装系统阶段不挂蓝牙**:`config.plist` 把蓝牙三件套(`BrcmBluetoothInjector` /
   `BrcmFirmwareData` / `BrcmPatchRAM3`)关掉,装完系统再换成 `config-full.plist`。
   我们那次 panic 正是 `BrcmPatchRAM3` 在 BaseSystem 下崩的,和它「装系统时尽量少挂东西」
   的做法完全吻合。
2. **ACPI 保留原样**:`ACPI/Add` 和 `ACPI/Patch` 没有清空。理由很实在——这份 ACPI 组合
   已经在这台机器上实测能进安装器,清空等于同时引入一批没验证过的变数。
3. **不学它换 SMBIOS**:它装系统时用原生支持的 `MacBookPro12,1`、日常换回 `9,1`;
   我们全程保持 `MacBookPro9,2`,靠 `Skip Board ID Check` + `-no_compat_check` 绕过板号检查。
   X230 只有核显,`9,2` 就是最贴近它的机型(理由见 [`../OCLP.md`](../OCLP.md) 第 7 节),
   没必要为安装单独换一套。
4. **不学它切 USB 地图**:它安装期 `USBInjectAll`、日常切 `USBPorts` 地图;
   我们全程 `USBInjectAll`,少一个要维护的开关。

## 它要求的 BIOS 改动(本仓库照做)

它的 `Other/README_HARDWARE.md` 里有一张「刷完 mod BIOS 之后建议改的设置」表,
其中和图形直接相关的一条:

| 路径 | 设置 |
|---|---|
| `Advanced → System Agent (SA) Configuration → Graphics Configuration` | **DVMT Pre-Allocated = `128MB`** |

它推荐的刷法就是 [n4ru/1vyrain](https://github.com/n4ru/1vyrain/)(不用编程器)。
这两项在出厂 BIOS 里是隐藏的,不刷看不到。

**和 EFI 的关系**:BIOS 这边决定显卡预留了多少,EFI 那边
(`framebuffer-stolenmem`)声明显卡认为自己能拿走多少 —— 两边必须对齐,
否则驱动会去用一段 BIOS 根本没预留的内存。本仓库的取值和对齐方式见
[`../踩坑记录.md`](../踩坑记录.md) 第 10 节。
